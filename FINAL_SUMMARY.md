### 2. Include Context
❌ "How do I document this?"

### 3. Use Real Examples
❌ "Document an endpoint"
✅ "Document POST /api/chat which creates a new conversation"

### 4. Include Constraints
❌ "Make it secure"

- [ ] All endpoints have authentication
