## 🎓 Bagaimana Menggunakan Templates

### Workflow Umum
```
1. Temukan masalah/kebutuhan
2. Pilih template yang sesuai
3. Copy template
4. Isi dengan detail spesifik
5. Submit ke AI assistant
6. Dapatkan hasil lengkap
```

### Contoh Workflow: Dokumentasi API Chat
```
Kebutuhan: Dokumentasi untuk POST /api/chat endpoint

Langkah:
1. Open: 02-API_DOCUMENTATION.md
2. Copy template "Endpoint: [NAME]"
3. Fill:
   - Method: POST
   - Endpoint: /api/chat
   - Purpose: Create new conversation
   - Request body: { "title": "string" }
   - Response: { "id": 1, "title": "...", ... }
4. Submit ke AI
5. Result: Complete documentation untuk endpoint

Time: ~5 menit untuk 1 endpoint
```
